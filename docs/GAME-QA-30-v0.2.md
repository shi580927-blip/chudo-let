# ЧУДОЛЁТ — игровая библиотека v0.2: сводный GAME/ART/PRINT-аудит

Дата: 8 ноября 2026. Репозиторий: `shi580927-blip/chudo-let`. Рабочая ветка: `develop/activity-library-v0.2`. Контрольная ветка `alpha/v0.1.0` не изменена.

## Итог по механикам

**30 из 30 алгоритмически реализованы**, по шести мирам и четырём возрастным профилям с фильтрацией допустимых типов:

1. Внимание: Найди предметы, Найди отличия, Чья это тень?, Что изменилось?, Найди лишнее.
2. Логика: Продолжи ряд, Разложи по группам, Найди пару, Таблица признаков, Мини-судоку.
3. Пространство: Лабиринт, Путешествие по карте, Собери картинку, Фигуры-конструкторы, Зеркальная половинка.
4. Математика: Сосчитай находки, Больше/меньше/поровну, Математическая дорожка, Составь число, Магазин приключений.
5. Речь: Собери слово, Слоговый конструктор, История по порядку, Кроссворд с картинками, Закончи фразу.
6. Приключения: Секретный шифр, Волшебный рюкзак, Маленький детектив, Приключение с выбором, Командная миссия.

### Недостающие ранее механики

- **№25 «Закончи фразу»**: 26 различных предложений, выбор из четырёх ответов, единственный эталонный вариант; объяснение взрослому и лист для печати.
- **№28 «Маленький детектив»**: четыре персонажа с двумя независимыми признаками. Каждая улика по отдельности подходит двум подозреваемым; пересечение двух улик однозначно выделяет одного. На экране и в PRINT правильный ответ до проверки не подсвечивается.
- **№29 «Приключение с выбором»**: 20 самостоятельных сюжетов по три последовательных решения. Неправильный выбор приводит к тупику, не выдаёт правильный ответ и позволяет попробовать другую ветвь. Печатный вариант выводит все три этапа; ключ — в ответах взрослому. Это **локальная игра с условными ветками**, не большой нелинейный движок.
- **№30 «Командная миссия»**: три роли (Разведчик, Мастер, Навигатор), по одной математической подсказке на роль; объединённый трёхзначный код; карточки можно раскрывать по очереди, печатать и распределять между детьми. Это **совместная игра на одном устройстве или бумаге**, без сетевого мультиплеера.

## Антиповторы

- Для каждого типа `contentKey` сравнивает существенное условие без seed и перестановок карточек.
- Все 30 типов генерируют **20 различных смысловых условий** в проверенных полных наборах для каждого подходящего возраста и шести тематических миров.
- «Фигуры-конструкторы»: 20 конкретных сюжетных SVG-силуэтов без повторов в комплекте из 20; пять разных деталей на фигуру.
- «История по порядку»: 20 четырёхшаговых причинно-следственных сюжетов вместо одного.
- «Найди пару»: 28 разных смысловых пар.
- «Тени» и «Лишнее»: по 24 предмета на каждый мир.
- «Слова/слоги»: не менее 20 подходящих записей на мир и на каждый из двух видов для возраста 5–6; у слов явно задана разбивка по слогам.
- «Шифр»: тематические слова отбираются из объединённого словаря, их разрешённая длина проверяется.

## ART-проход по 20 фигурам

По скриншотам пользователя исправлены гриб и бабочка: ровные пятнышки на шляпке, трава придвинута к ножке; крылья бабочки сближены с туловищем, пятнышки подняты. Ранее исправлены лодочка, робот, ракета, замок, улитка, зонтик, подводная лодка, паровозик и снеговик. Геометрические фигуры выполняются точными редактируемыми SVG, а не нейросетевыми картинками с ошибками в контурах.

## Контроль

- Последняя проверка GitHub Actions: **81 тест, 81 прошло, 0 ошибок** — https://github.com/shi580927-blip/chudo-let/actions/runs/42518636353.
- Проверены алгоритмы решений, воспроизводимость по seed, 20/20 смысловая уникальность, отсутствие видимого спойлера, логика действий, незавершённые ответы, наличие игровых элементов и создание PRINT-версии.
- Новые языковые записи и ассоциации требуют редакционного просмотра глазами и, где возможно, детской апробации: emoji не всегда передают точный предмет без подписи.
- **ART:** последние правки гриба и бабочки пользователь ещё не принимал; четыре новых вида заданий также нуждаются в оценке художественной подачи.
- **PRINT:** A4-разметка программно предусмотрена, но реальная печать, безопасные поля и проверка чернил физически не подтверждены.
- **Возраст:** методическая пригодность и реальное прохождение детьми 5–6, 7–9 и 10–12 лет не проверены.
- **Статус:** `готово к ручной проверке`, **не** `проверено`, **не** `опубликовано` и **не** готовый коммерческий продукт.

## Как проверить локально

1. GitHub Desktop: выбрать `develop/activity-library-v0.2`, нажать `Fetch origin` и `Pull origin`.
2. VS Code + Live Server: открыть `index.html` и обновить страницу `Ctrl + F5`.
3. В селекторе «Содержание» выбрать отдельно каждую из четырёх новых механик и установить количество `20`.
4. Проверить правильный и неверный ответы, подсказку, мобильную ширину, печать А4 и наглядность новых текстовых иллюстраций.
5. `preview/tangram-20.html` — все двадцать фигур рядом для ART-проверки.

Контрольную альфу не объединять с этой веткой до пользовательской и педагогической приёмки.
