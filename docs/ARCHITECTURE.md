# Архитектура библиотеки заданий «ЧУДОЛЁТ» · 0.1

## Назначение
Создание достоверных развивающих заданий, PDF-сборников и будущих HTML5-квестов без случайных визуальных/логических ошибок. Источник истины — структурированные данные + проверяемый алгоритм; иллюстрации не должны определять ответ.

## Покрытие
30 механик в 6 категориях: внимание, логика, пространственное мышление, математика, речь и приключения. В MVP программно реализованы 10: 01 Поиск предметов, 03 Чья это тень?, 05 Найди лишнее, 06 Продолжи ряд, 07 Разложи по группам, 08 Найди пару, 11 Лабиринт, 16 Сосчитай находки, 17 Больше/меньше/поровну, 23 История по порядку.

Оставшиеся 20 перечислены в CATALOG со статусом ready:false. Недопустимо обозначать их готовыми.

## Контракт
Bundle: schema, title, age, theme, count, seed, focus, tasks[].
Task: id, kind, title, theme, age, seed, prompt и специфические поля; сохраняется правильный ответ либо проверяемая структура маршрута/классификации. Сохранять поля seed, kind, theme в опубликованных выпусках.

## Алгоритмы и проверка
- Поиск/счёт: количество целевых объектов совпадает с ответом.
- Силуэты/пары/ряды: правильный ответ входит в уникальные варианты.
- Лишний предмет: пять или три предмета из одной из двух заранее заданных категорий, один из противоположной.
- Сортировка: все объекты принадлежат одной из двух заданных категорий.
- Лабиринт: связное дерево на квадратной сетке; число рёбер равно N²-1, путь находится BFS. Подвижный маркер идёт только по соединённым клеткам. В PDF указан маршрут.
- Сравнение: вычисление точного знака по числам.
- История: действия пронумерованы по осмысленному сюжету; проверяется порядок.

## Форматы
- Экран: доступные кнопки, адаптивная сетка, игровые подсказки и обратная связь.
- А4: CSS @page, титульный лист, задания, отдельный ключ для взрослых; диалог печати браузера.
- JSON: полный выпуск, включая ответы, для импорта в будущий движок.

## Ограничения MVP
В печатных заданиях необходимо улучшить поля для рисования/соединений; эмодзи заменить на авторскую графику бренда. Нужен редакторский предпросмотр для каждой механики, реальная проверка возрастной сложности и пилотные тесты с детьми. Автоматически проверенное задание не считается педагогически утверждённым.
