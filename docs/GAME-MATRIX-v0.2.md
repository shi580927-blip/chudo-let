# ЧУДОЛЁТ — GAME-матрица новых механик v0.2

Дата: 07.11.2026. Статус: **GAME алгоритмически проверено; ART/PRINT и тесты с детьми — ожидают ручной приёмки**.

В этом файле фиксируются вход, действие ребёнка, однозначный ответ, переход и два уровня подсказок. Игра сохраняет прежние цветные, объёмно выглядящие эмодзи из принятой альфы, не использует отклонённые плоские SVG.

## №12 «Путешествие по карте» (5+)

| Поле | Значение |
|---|---|
| Вход | Тема, возраст, seed; воспроизводимая сетка 4×4 для младших или 5×5 для старших; старт 🚩 |
| Действие | Пройти по очереди 4–7 стрелок ↑↓←→ и определить предмет в конечной клетке |
| Однозначный ответ | Точное местоположение вычисляется проходом по направлениям; найденный предмет один |
| Ключ | Массив координат пути и значок финиша; три ложных ответа — другие уникальные предметы на карте |
| Переход | При правильном ответе фиксируется решение, появляется возможность перейти к следующему заданию |
| Подсказка 1 | Найди флажок — это первая клетка |
| Подсказка 2 | Выполняй каждую стрелку по одной; ↑ — на клетку выше, → — на клетку правее |
| Спойлер | Финиш не выделен. Ответ — только в JSON-паспорте и разделе для взрослых после печатного комплекта |

**Контроль GAME:** маршрут не выходит за сетку, не посещает клетки повторно, имеет заданную длину; все значки ориентиров уникальны. `validateTask` сверяет сохранённый и независимо вычисленный путь. Нарушенные маршруты отклоняются.

**Контроль PRINT:** флажок, маршрут, карта и четыре значка выводятся без подсветки ответа, с полями А4. Требуется реальная пробная печать.

## №26 «Секретный шифр» (7+)

| Поле | Значение |
|---|---|
| Вход | Тема, возраст, seed; слово из тематического словаря |
| Действие | Прочитать символы и собрать слово нажатием букв по ключу |
| Однозначный ответ | Все символы однозначно соответствуют буквам; ключ полон и инъективен |
| Ключ | Полная таблица символ → буква для каждой буквы слова плюс три отвлекающие буквы |
| Переход | После полного правильного слова показывается успех |
| Подсказка 1 | Найди первый символ в таблице ключа |
| Подсказка 2 | Для каждой буквы повтори поиск по ключу; одинаковые символы означают одинаковые буквы |
| Спойлер | Собранное слово заранее не отображается в интерфейсе. Перемешанная таблица даёт ключ, но не готовую последовательность |

**Контроль GAME:** ключ покрывает все буквы и не содержит дублирующихся символов/букв; шифр совпадает с эталоном; проверить можно только полную строку.

**Контроль PRINT:** печатаются шифр, ключ, пустые места для букв, ответ отдельно для взрослого.

## №19 «Составь число» (5+)

| Поле | Значение |
|---|---|
| Вход | Тема, возраст, seed; количество сотен (для старших), десятков и единиц |
| Действие | Сосчитать разрядные группы и собрать число цифровой клавиатурой |
| Однозначный ответ | Значение `hundreds*100 + tens*10 + ones`, без ведущего нуля |
| Ключ | Полное разложение числа на сотни, десятки и единицы |
| Переход | После заполнения всех цифр и правильного ответа показывается успех |
| Подсказка 1 | Одна длинная полоска с точками — это десять |
| Подсказка 2 | Крупный квадрат — сто, десятки — по десять, отдельные кружки — по одному |
| Спойлер | В игре отображаются только группы, не итоговая сумма; число в ключе для взрослого |

**Контроль GAME:** десятки 0–9, единицы 0–9; сотни (0–3) разрешены старшим; ввод по одному символу, неполная запись не оценивается как ошибка.

**Контроль PRINT:** печатаются счётные группы и пустые клеточки для ответа, готовая сумма — в ключе для взрослого.

## Сводка испытаний

- По 1920 вариантов каждой механики в автоматизированных тестах: 6 миров × 4 группы возраста × 80 значений seed; в сумме 5760.
- Отдельные UI-тесты: правильный путь, полный/частичный шифр и число, работа поля ответа.
- GitHub Actions: зелёный после исправления возраста в UI-тесте.
- Возрастная фильтрация: в одиночном режиме механика не предлагается младшим группам, где она не подходит.
- **Требуется ручная приёмка:** читаемость схем на Android, касания клавиш, печать А4 при 13-мм полях и живое прохождение детьми, особенно возраста 5–7.
