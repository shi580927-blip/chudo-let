# ЧУДОЛЁТ — GAME-матрица речевых заданий, v0.2

**Статус:** рабочая версия, алгоритмически проверено; требуется ручная проверка ART, PRINT и живое прохождение детьми. В каталоге 20 из 30 механик. Прежний объёмный вид предметов сохранён.

## №21 «Собери слово» — от 5 лет

| Требование | Реализация |
|---|---|
| Вход | Тема, возраст, seed, редакционный словарь с однозначной картинкой-подсказкой |
| Действие | Посмотреть на картинку, выбрать перемешанные буквы в правильном порядке |
| Ответ | Точное слово из словаря в именительном падеже (строчные/заглавные в игровом ключе не смешиваются) |
| Ключ | `answer` — правильное слово; `tiles` — анаграмма его букв, включая повторяющиеся с разными индексами |
| Переход | После выбора всех карточек доступна осмысленная проверка; правильное слово открывает следующий шаг |
| Подсказка 1 | Назови предмет на картинке |
| Подсказка 2 | Попробуй выбрать первую букву, затем произноси слово по звукам |
| Спойлеры | До ответа слово не выводится в видимой карточке, игровая часть печати содержит пустые клетки |
| Контроль | Все буквы используются один раз; порядок в исходных плитках не совпадает с ответом; размер слов зависит от возраста |

## №22 «Слоговый конструктор» — от 5 лет

| Требование | Реализация |
|---|---|
| Вход | Тема, возраст, seed, запись слова и отдельно проверенная последовательность слогов |
| Действие | Произнести слово, собрать слоговые карточки в правильном порядке |
| Ответ | Объединение слогов даёт ровно слово из словаря |
| Ключ | `tiles` — те же слоги в перемешанном порядке, `answer` — эталонная последовательность букв |
| Переход | После сборки всех слогов правильный ответ переводит к следующему заданию |
| Подсказка 1 | Посмотри на рисунок и назови предмет |
| Подсказка 2 | Произнеси слово медленно по слогам и найди первый |
| Спойлеры | Слоги представлены в перемешанном порядке; готовое слово — только в ключе взрослого |
| Контроль | Слоги не генерируются случайными разрывами букв; используется редакционно подготовленная разбивка; одинаковые слоги в одном задании исключены |

## №24 «Кроссворд с картинками» — от 7 лет

| Требование | Реализация |
|---|---|
| Вход | Тема, возраст, seed; три слова из одного тематического словаря и три разные картинки-подсказки |
| Действие | Вписать буквы в клетки трёх слов: два по горизонтали и одно по вертикали |
| Ответ | Заполненная сетка; буквы двух пересечений должны совпасть |
| Ключ | `entries` с координатами, направлениями, номерами и словами; `solution` — эталонные буквы сетки |
| Переход | При неполной сетке — просьба закончить, при верном полном ответе — успех |
| Подсказка 1 | Начни с картинки, предмет на которой знаком |
| Подсказка 2 | Буква на пересечении одинакова для обоих слов |
| Спойлеры | При игре/печати сетка пустая; правильные буквы в JSON и на отдельной странице ответов взрослому |
| Контроль | Ровно три различных слова, два фактических пересечения с одинаковыми буквами, никакого конфликта в ячейках, валидная сетка и координаты; цифровая/мобильная клавиатура русских букв |

## Проверки и ограничения

- Словарь `src/words.mjs` содержит тематические слова, связанные с узнаваемыми игровыми значками. Словесные задания используют этот источник; шифр прежней версии остаётся отдельной механикой.
- Автотесты: 6 миров × 4 возрастные настройки × 100 вариантов × 3 механики = **7200 наборов**. Проверяются правильные и заведомо ошибочные ответы.
- UI-тесты: сборка букв, слогов, кроссворда, неполные ответы, полная корректная проверка.
- Возраст: «Собери слово», «Слоговый конструктор» — с доступной группы 5–6; кроссворд — с группы 7–9.
- PRINT: HTML-макет и оформление для печати А4 предусмотрены; физическую пробную печать ещё не проверяли.
- ART: оставлены принятые пользователем цветные эмодзи, не заменены на отклонённые плоские SVG.
- **Не переносить в alpha/main без ручной приёмки и отдельного решения.**
