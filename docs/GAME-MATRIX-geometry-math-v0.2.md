# ЧУДОЛЁТ — GAME-матрица новых заданий v0.2 (геометрия и математика)

Дата: 08.11.2026. Статус: **GAME — проверено автоматическими тестами; ART/PRINT — ожидает ручной приёмки**. Новые механики добавлены только в рабочую ветку, без изменения контрольной альфы.

## №14 «Фигуры-конструкторы» (от 5 лет)

- **Вход:** тема, возраст, номер варианта; готовая геометрическая схема из пяти точно определённых деталей (домик, ракета, робот, кораблик).
- **Действие:** ребёнок выбирает место по номеру и устанавливает подходящую цветную фигуру; занятую позицию можно освободить.
- **Ответ:** упорядоченное соответствие пяти деталей пяти позициям; каждый идентификатор используется один раз.
- **Ключ:** `parts` содержит точные формы, цвета и координаты; `tray` — перемешанный комплект; `answer` — эталонная расстановка.
- **Переход:** кнопка проверки оценивает только полностью собранную фигуру; неполная сборка просит закончить работу.
- **Подсказка 1:** найди одинаковые контуры.
- **Подсказка 2:** выбери фигуру для конкретной позиции, сверяй ориентацию с образцом.
- **Контроль спойлеров:** начальная схема содержит контуры без цветных деталей и без правильной последовательности; неправильная деталь визуально устанавливается в выбранную позицию, а не помечается автоматически как ошибочная.
- **ART:** геометрические рисунки точные SVG, но художественная композиция — технический прототип, а не утверждённая иллюстрация.
- **PRINT:** отдельные геометрические детали и контуры на А4; требуется проверка вырезания, размера и полей.

## №18 «Математическая дорожка» (от 5 лет)

- **Вход:** возраст, номер варианта; стартовое число, 3–5 действий и три ответа к каждому шагу.
- **Действие:** последовательно выполнить действия и выбрать один результат в каждой строке.
- **Ответ:** массив индексов правильных вариантов; для каждого шага правильный результат совпадает с результатом арифметики.
- **Ключ:** `start`, `steps[{op,amount,options,answer,result}]`; нет одинаковых вариантов в пределах шага.
- **Переход:** проверка только когда выбран ответ на каждом шаге. Ошибочный полный ответ можно исправить.
- **Подсказка 1:** начни со стартового числа.
- **Подсказка 2:** используй результат предыдущей операции как исходное число следующей.
- **Контроль спойлеров:** начальный интерфейс и печатные листы показывают примеры и варианты ответов, но ни один из них не выделяется автоматически.
- **Возраст:** 5–6 лет — небольшое сложение; 7–9 лет — сложение и вычитание; 10–12 лет — также иногда удвоение. Сложность и педагогический баланс требуют реального тестирования.
- **PRINT:** крупные варианты для отметок; испытать на А4.

## №20 «Магазин приключений» (от 5 лет)

- **Вход:** тема, возраст, номер варианта; 5–6 товаров, цены, бюджет, число товаров для покупки.
- **Действие:** выбрать ровно 2 или 3 товара, сумма цен которых точно равна содержимому кошелька.
- **Ответ:** отсортированный набор индексов товаров (порядок нажатий не важен).
- **Ключ:** `items[{icon,price}]`, `take`, `budget`, `answer`.
- **Переход:** пока выбранных товаров недостаточно, показывается просьба закончить набор; проверка полного набора определяет успех или ошибку.
- **Подсказка 1:** сначала обрати внимание на количество товаров.
- **Подсказка 2:** сложи цены выбранных товаров; сумма должна совпасть с кошельком.
- **Контроль спойлеров:** ни один товар изначально не выделен. При печати галочки остаются пустыми даже после решения задания на экране.
- **GAME:** генератор вычисляет **все** комбинации нужного размера и выбирает только бюджеты с единственной правильной комбинацией; валидатор повторно проверяет уникальность.
- **PRINT:** детские карточки с товарами, ценами и пустыми отметками; ключ на отдельной странице для взрослого.
