# ЧУДОЛЁТ — QA-галерея 30 × 20

Дата: 8 ноября 2026. Репозиторий: shi580927-blip/chudo-let. Рабочая ветка: develop/activity-library-v0.2.

## Цель
В одной странице проверять не 7, а все 20 вариантов каждой из 30 игровых механик, вести последовательную приёмку GAME → ART → PRINT и фиксировать ошибки для дальнейших исправлений. Генераторные задания сохраняют однозначные ответы, а сам QA-инструмент не обозначает их проверенными автоматически.

## Запуск
1. В GitHub Desktop: ветка develop/activity-library-v0.2 → Fetch origin → Pull origin.
2. В VS Code запустить Live Server из корня проекта.
3. Открыть index.html и нажать «QA-галерея 30×20» или открыть preview/qa-gallery.html через Live Server.
4. По умолчанию: «Облачная почта», 10–12 лет, seed 20261107. Это 30 × 20 = 600 вариантов для одного мира, возраста и seed. Для младших возрастов часть типов фильтруется по minAge.
5. Можно выбрать конкретный мир, возраст, направление, название механики, статус, seed и поиск по названию. Каждый раздел раскрывает свои 20 миниатюр. «Развернуть все» выводит все подходящие разделы.

## Проверка
Нажать на карточку — откроется настоящий интерактивный экран игры с точно теми же настройками и номером задания. В игре можно проверить правильные и неправильные ответы, подсказки и взаимодействие. Отдельно есть ссылка «Открыть на весь экран».

Справа — скрытый до открытия ответ для редактора и форма проверки:
- Ещё не проверено / Без замечаний / Нужна правка.
- Теги GAME, ART, PRINT, UX, TEXT.
- Замечание до 3000 знаков.
- Сохранить отметку; при переходе на соседнее задание или закрытии несохранённая отметка тоже сохраняется.
- Счётчики и фильтры по статусам помогают возвращаться к непроверенным или проблемным задачам.

## Хранение и экспорт
Отметки хранятся в localStorage этого браузера под ключом chudolet:qa-reviews:v1. Никаких аккаунтов, внешней передачи и персональных данных детей не требуется. Параметры записи: theme / age / seed / kind / index. Отдельно записывается отпечаток существенного содержания, чтобы обнаружить устаревшие записи после изменения движка.

Обязательно после сеанса скачать JSON отчёт, иначе сброс браузерного хранилища может уничтожить локальные отметки. Загрузка другого отчёта добавляет отсутствующие записи. Конфликты не перезаписывают существующие заметки — их копии выгружаются отдельным JSON для ручного сверения. Автоматического удаления заметок нет.

## Критерии ручной приёмки
GAME: ответ однозначен, 20 заданий действительно разные, подсказки не показывают разгадку, ошибки дают верную обратную связь.

ART: предмет узнаваем, детали не обрезаны, контуры соединены, номера расположены внутри фигур, изображения различимы на телефоне.

PRINT: А4, безопасные поля минимум 12 мм, правильные схемы, крупные шрифты, экономичный расход чернил, ответы отдельно от детской части.

UX: кнопки доступны на телефоне, нет горизонтального обрезания, подсказки и награды понятны ребёнку.

Живое прохождение: дети должны самостоятельно понимать задания и давать правильные ответы; записывать затруднения и время без подсказок автора.

## Код и автоматические проверки
- src/qa-core.mjs: стабильные ключи, статусы, безопасный импорт/экспорт, контроль конфликтов.
- src/qa-gallery.mjs: фильтрация, 20 миниатюр, модальный полнофункциональный просмотр, запись замечаний.
- assets/qa-gallery.css: фирменный адаптивный интерфейс с утверждённым растровым логотипом.
- src/app.mjs: точные ссылки qa=1 с возрастом, темой, номером варианта, типом и индексом. Для полноэкранного режима full=1.
- tests/qa-core.test.mjs, tests/qa-gallery.test.mjs: безопасный merge, миниатюры всех 30 типов, 540 детерминированных переходов, существование элементов и синтаксис JS.

Статус: код готов к ручной оценке, автоматические проверки прошли. Кросс-браузерный визуальный осмотр, реальные печатные тесты и детская апробация пока не подтверждены. Контрольная alpha/v0.1.0 не менялась.
