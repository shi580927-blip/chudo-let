# ЧУДОЛЁТ — Аудит повторов в комплектах из 20 заданий

**Проверено:** 08.11.2026, ветка \`develop/activity-library-v0.2\`. В генераторе 26 реализованных механик из 30 планируемых. Каталог из четырёх оставшихся игр в аудит не входит.

## Метод
Для каждого типа отдельно создавались комплекты из 20 заданий по 6 игровым мирам, группам 5–6, 7–9 и 10–12 лет (если тип разрешён) и трём начальным seed. Сравнивали **содержание**, а не служебные идентификаторы: одинаковое слово в новом шифре = повтор, одинаковый предмет тени с другой перестановкой ответов = повтор. Проверены 54 комплекта на тип (для типов от 7 лет — 36). Затем в генератор добавлена функция \`contentKey\` и подбор неповторяющегося содержания.

## Качество и ограничения
- Программные тесты доказывают отсутствие повторов по принятому ключу содержания, но не гарантируют, что все варианты художественно и методически удачны.
- Установка «20» доступна для каждого отдельного типа; для семи ограниченных типов программа пока вынужденно повторяет исходные слова/предметы после исчерпания набора. Без пополнения материалов невозможно получить 20 принципиально новых сюжетов.
- Не считать повтор одной истории с новым порядком карточек новым заданием.
- Не допускать объединения в \`alpha\` без ручной приёмки ART/PRINT и детского прохождения.

## Следующие работы
1. Создать 20 разных четырёхэтапных историй, подходящих возрасту, с однозначным порядком.
2. Подготовить 20–24 узнаваемые смысловые пары, исправить неоднозначные ассоциации.
3. Расширить тематические словари до 20–25 различных слов с картинками, слогами и ключом шифров.
4. Для «Теней» и «Лишнего» увеличить фактический состав предметов каждого мира; не принимать косметическую перестановку как уникальность.
5. Повторно протестировать 20/20, затем ART/PRINT и живую проверку детьми.

- «Найди пару»: 28 смысловых ассоциаций с различными исходными предметами и ответами вместо восьми.
- «Чья это тень?» и «Найди лишнее»: для каждой из шести тем теперь по 24 предмета в двух ясно разделённых категориях.
- «Собери слово» и «Слоговый конструктор»: во всех шести темах не менее 20 отдельных допустимых записей для возрастной группы 5–6 лет; отдельные короткие слова и слоги проверены на программном уровне.
- «Секретный шифр»: берёт слова из объединённых тематических словарей, а не старого мини-списка.
