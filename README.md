# ЧУДОЛЁТ — библиотека заданий

Рабочая копия v0.2 на основе принятой Alpha 0.1.0. Разработка ведётся отдельно от зафиксированной альфы. Все интерфейсы на русском языке.

**Что реально работает сейчас:** каталог 30 механик; 10 алгоритмических генераторов (find, shadow, odd, sequence, sort, pair, maze, count, compare, story); 6 тем; 4 возрастных группы; наборы по 3–20 заданий; воспроизводимый номер варианта; интерактивное решение и проверка; подсказки; печать А4 с ответами; экспорт JSON. Остальные 20 механик — документированный план, пока не реализованные игры.

## Запуск

Без установки зависимостей: командой python3 -m http.server 8000 из корня репозитория, затем откройте http://localhost:8000. Либо npm run start. Требуется HTTP-сервер, потому что браузерные ES-модули не должны загружаться напрямую через file://.

Проверка генераторов: npm test (Node.js 20+). В браузере приложение работает без Node.js, внешних JS-библиотек, шрифтов и API.

## Структура

- index.html — интерфейс конструктора
- assets/style.css — адаптивная дизайн-система и стили печати А4
- src/engine.mjs — чистые функции генерации, расчёта ответов и автоматической проверки
- src/app.mjs — браузерная игра и взаимодействия
- tests/engine.test.mjs — тесты генераторов, маршрутов и повторяемости
- docs/ARCHITECTURE.md — паспорт библиотеки, требования и дорожная карта

## Три ключевых ограничения

1. Эмодзи — временные заменители иллюстраций, а не утверждённый визуальный стиль «ЧУДОЛЁТА». Художественные SVG/PNG/WEBP подключаются отдельными ресурсами после утверждения графики.
2. «Сохранить PDF» выполняется через системный диалог печати браузера. PDF не отправляется на сервер.
3. Данная версия — редакторский прототип. Перед продажей материалов требуется педагогическая и визуальная проверка, особенно смысловой однозначности заданий «найди лишнее», «найди пару» и сценарных заданий.

## Безопасность и приватность

Нет форм персональных данных, аналитики, cookies, внешних запросов и хранения аккаунтов. Генерация выполняется локально в браузере. Созданный JSON скачивается на компьютер пользователя.

## Режим публикации

Открытие index.html из GitHub Pages возможно после включения Pages владельцем репозитория. Этот PR сам по себе не активирует GitHub Pages и не публикует продукт в интернет.

## Художественные SVG в v0.2 (эксперимент)

В папке assets/items/clouds/ находятся 12 отдельных редактируемых SVG игровых предметов для темы «Облачная почта». Файл src/artwork.mjs сопоставляет прежние символы из JSON заданий с иллюстрациями, не изменяя ответы. В остальных пяти темах остаются эмодзи. После просмотра пользователь отклонил плоскую графику как уступающую прежним объёмным эмодзи. **По умолчанию во всех заданиях снова отображаются исходные эмодзи из альфы**, включая печать. Экспериментальные SVG сохранены только для сравнения и не включаются автоматически. Для явного предпросмотра разработчик может вызвать renderSymbol(symbol, theme, "illustrated"). Эти векторные предметы не утверждены для коммерческого использования. Официальный логотип не изменялся.

## Новая механика «Найди отличия» (v0.2)

Генератор создаёт две сетки с общим расположением и заменяет ровно 3–6 предметов в зависимости от возраста. Ребёнок отмечает изменения на правой картинке; автоматическая проверка сравнивает точные позиции. На телефоне картинки располагаются вертикально, при печати предусмотрено пространство для отметок. Эта механика не основана на случайном рисовании двух независимых изображений.

## Новые механики v0.2: память, таблица, мини-судоку

**Что изменилось?** (4+): сначала на экране показывается сцена из 4 или 6 различных объектов, затем после кнопки «Я запомнил» один предмет исчезает. Ответ один, исходный экран не виден во время выбора. В печатной версии обе сцены доступны одновременно.

**Таблица признаков** (5+): таблица 3×3 или 4×4 с двумя независимыми рядами признаков. На пересечении нужно восстановить конкретную пару символов; четыре варианта ответа проверяются алгоритмически.

**Мини-судоку** (5+): проверяемое судоку 4×4 с квадратами 2×2. Алгоритм удаляет подсказки только если у головоломки сохраняется ровно одно решение. Для разных возрастов — разное количество скрытых клеток. Все ответы сохранены в JSON и доступы взрослым в отдельном ключе.

Для тестирования этих механик в конструкторе появилось меню «Содержание → Только …». На телефоне таблицы и клетки масштабируются. Всё ещё требуется ручная ART/PRINT/возрастная проверка.

## Корректировки по проверке пользователем
- «Что изменилось?»: 3 ложных варианта выбираются из предметов, которых не было на исходной сцене; правильный ответ никогда не первый. Проверяется память, а не простое сравнение видимых вариантов.
- «Таблица признаков»: оба значка на пересечении увеличены, отступы уплотнены на компьютере, телефоне и в А4.
- «Мини-судоку»: при частичном заполнении кнопка «Проверить» выводит просьбу закончить все пустые клетки; сообщение «Не совсем» остаётся только для полного, но неверного ответа.

## Карта, шифр и числовой конструктор (v0.2)
- «Путешествие по карте» (5+): генерируется действительный путь по сетке (4×4 или 5×5) без выхода за края и повторных клеток. Финиш определяется строго последовательностью стрелок; четыре разных варианта ответа, корректный один. На карте используются крупные цветные значки.
- «Секретный шифр» (7+): слово из тематического словаря кодируется геометрическими символами. Полный ключ содержит все использованные буквы и три дополнительные, находится в перемешанном порядке. Ребёнок собирает буквы кнопками; печатная версия показывает ключ и пустые места для ответа, не печатает правильное слово.
- «Составь число» (5+): группы сотен, десятков (по 10 точек) и единиц изображаются отдельно. Цифры собираются на клавиатуре и проверяются только после полного ввода. Для детей 10–12 лет добавляется разряд сотен.
- Каждую механику можно выбрать отдельно в конструкторе. Тесты проверяют игровую матрицу, ложные ответы и полный интерактивный сценарий.

## Три речевых механики (v0.2)

Добавлены «Собери слово» (5+), «Слоговый конструктор» (5+) и «Кроссворд с картинками» (7+). Все задания строятся на отдельных проверяемых тематических словарях `src/words.mjs` (6 миров; сопоставление каждой картинки с конкретным русским словом и заранее прописанными слогами). В словах и слогах порядок карточек перемешан; ребёнок нажимает карточки, использованные нельзя выбрать повторно. В кроссвордах три предмета-подсказки, три слова, два настоящих пересечения, интерактивный ввод по клеткам с русской клавиатурой. Печатная версия содержит пустое поле и ключ отдельно для взрослого. Неполный ответ не считается ошибкой. Дополнительные тесты перебирают разные варианты и проверяют сходящиеся буквы и правильность слов. Статус художественной и печатной приёмки: требуется ручная проверка.

## Исправление повторяющихся слов в слоговом конструкторе

Для режима «Только Слоговый конструктор» выбор слова теперь идёт **без возврата в пределах цикла**: сначала расходуются все подходящие слова данной темы, затем начинается новый перемешанный цикл. При переходе к следующему циклу дополнительно избегаем слов, встречавшихся в трёх последних речевых заданиях. Для возраста 7–12 лет в упражнении участвуют не только слова из трёх и более слогов, но и двухсложные: прежнее ограничение оставляло в некоторых мирах всего 3–4 слова. Возрастную сложность заданий позднее потребуется настроить методически. Если комплект длиннее словаря (например, 20 заданий при 10 разных словах), дальние повторы возможны; подряд и через 1–2 задания повторы отлавливаются автоматическими тестами. Словари и правильные ответы остались без изменений.

## Пространственные и приключенческие задания — прототип v0.2

Добавлены проверяемые механики «Собери картинку» (4 или 9 фрагментов), «Зеркальная половинка» (один правильный из трёх вариантов) и «Волшебный рюкзак» (выбор предметов по двум или трём ограничениям, строго одно решение). Алгоритмы в `src/spatial.mjs` независимы от интерфейса и проверяют ответы. Визуальная сцена пазла `src/scene.mjs` — программно нарисованный прототип, пока не художественно утверждённая иллюстрация. Подготовлена экранная и печатная версия. GAME-проверка автоматизирована, визуальную, педагогическую и печатную приёмку необходимо провести отдельно.
